# Contributing

Thanks for wanting to add something. The bar is simple: a working creator should be able to open the tool today and get value out of it this week.

## Adding a tool

Open a pull request that adds one entry, in the existing format:

```
**[Name](https://example.com):** one sentence on what it does and who it is for. `Freemium` · macOS, Windows
```

* Put it in the section where someone would look for it, in a sensible place rather than always at the end.
* Use the plain product URL. No affiliate links, no referral codes, no UTM tags.
* Price tag is one of `Free`, `Freemium`, `Paid`, `Open source`, or a short phrase such as `Revenue share`.
* Platforms come after the tag, separated by commas.

## What gets rejected

* Abandoned products, dead links, and tools in a closed waitlist.
* Duplicates of something already listed that add nothing new.
* Self promotion without disclosure. If you made it, say so in the pull request.
* Anything that pays for placement. Placement is not for sale here.

## Fixing the list

Reporting a dead link, a wrong price tag or a tool that is no longer worth using is as welcome as adding one. Open an issue or a pull request.
